### How I approach architecture

1. **Start from the failure modes.** Enterprise AI rarely fails on the model. It fails on retrieval quality, ungoverned data, missing audit trails and no way to measure regressions.
2. **Make quality measurable.** Every RAG or agent system I design ships with an evaluation loop and tracing, so changes are judged by evidence.
3. **Design for the regulator, not just the user.** In healthcare and insurance, auditability and data boundaries are requirements, not add-ons.
4. **Record the tradeoffs.** Significant decisions are written as Architecture Decision Records (ADRs) so the reasoning outlives the meeting.
